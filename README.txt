GERALD AC TECHNOLOGIES PORTFOLIO
================================

FILES
- index.html: website structure and content
- style.css: black-and-gold styling and responsive layout
- script.js: mobile navigation, current year, and email enquiry form
- assets/profile.png: your supplied profile picture

HOW TO RUN
1. Extract the ZIP file if you received it as an archive.
2. Keep index.html, style.css, script.js, and the assets folder together.
3. Open index.html in a browser such as Chrome or Edge.
4. Internet access is needed for the optional Google Fonts; the website otherwise uses fallback fonts.

IMPORTANT NOTES
- The contact form opens the visitor's default email app with a prefilled message. It does not send automatically and does not use a backend.
- The CV button has not been added as a live download because you do not have a CV file yet.
- Project cards currently use CSS-made concept illustrations. Replace them with actual project screenshots and add real project links when available.
- The six displayed project cards include examples/concepts based on details provided. Edit the project descriptions so they accurately reflect your work.
- Your full street address is not shown; only Enugu State, Nigeria is displayed for privacy.
- Review the service descriptions to ensure they match the services you are ready to offer clients.
